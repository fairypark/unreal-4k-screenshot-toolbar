# Fab Submission Handoff

This folder contains the local preparation materials for a free Fab listing.

## Files

- `ListingCopy.md`: Ready-to-paste listing title, descriptions, technical details, tags, and version notes.
- `Compatibility.md`: Verified Unreal Engine build matrix and known local blocker.
- `MediaSpec.md`: Final thumbnail verification, source-image audit, and media requirements.
- `ProjectFileLinks.md`: Planned public, no-login release asset URLs.
- `ReleaseNotes-v1.1.0.md`: Prepared release notes for configurable resolution.
- `SubmissionChecklist.md`: Publisher portal and final submission checklist.

## Local package outputs

The final verified ZIP files and SHA-256 manifest are generated outside the Git repository in the local Fab submission folder. They must be reviewed before upload.

## Actions intentionally left to the publisher

- Publisher onboarding, legal agreements, trader verification, tax, and payout details
- Final licensing and AI-usage policy choices
- Media upload and listing preview review
- Final Fab submission
