# Fab Submission Checklist

## Publisher account

- [ ] Complete Fab Distribution Agreement
- [ ] Complete Publisher Profile and Creator Code
- [ ] Complete Trader Verification
- [ ] Complete tax and payout setup

## Listing

- [ ] Create a `Tools & Plugins > Engine Tools` listing
- [ ] Select Unreal Engine Code Plugin
- [ ] Select Standard License
- [ ] Set price to Free
- [ ] Paste title, description, technical information, and tags from
      `ListingCopy.md`
- [ ] Confirm Mature Content is No
- [ ] Confirm the final AI disclosure in the Fab form
- [ ] Add documentation URL
- [ ] Add support URL

## Product versions

- [ ] Add Unreal Engine 5.8 / Win64 version and its direct ZIP link
- [ ] Add Unreal Engine 5.7 / Win64 version and its direct ZIP link
- [ ] Add Unreal Engine 5.0 / Win64 version and its direct ZIP link
- [ ] Paste the matching Version Notes from `ListingCopy.md`
- [ ] Do not advertise Unreal Engine 5.5 until its build blocker is resolved

## Media

- [ ] Upload a dedicated thumbnail
- [ ] Upload at least one gallery image
- [ ] Confirm every image is at least 1920 × 1080
- [ ] Confirm every image is less than 3 MB
- [ ] Confirm all gallery images together are less than 25 MB
- [ ] Confirm screenshots clearly distinguish included plugin functionality from
      scene content that is not included

## Package review

- [ ] Each Project File Link downloads without login or permission request
- [ ] Each ZIP contains exactly one plugin
- [ ] Each ZIP contains `.uplugin`, `Source`, `Content`, and `Config`
- [ ] Each ZIP excludes `.git`, `Intermediate`, `Saved`, and private build paths
- [ ] Each ZIP includes `Documentation.md` and `LICENSE`
- [ ] Validate the published SHA-256 hash against the local manifest

## Final review

- [ ] Check the rendered listing on desktop
- [ ] Check spelling, engine versions, platform, and download links
- [ ] Choose automatic or manual activation
- [ ] Click `Submit for review`
